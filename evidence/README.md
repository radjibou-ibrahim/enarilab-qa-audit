# Éléments de preuve

Ce dossier est réservé aux preuves utiles pour étayer les résultats de test.

## Règles de collecte

- Ajouter une preuve uniquement lorsqu'elle apporte une information utile à un scénario ou à un rapport.
- Nommer les fichiers avec l'identifiant du test ou du bug : `TR-001-resultat.png`, `BUG-001-reproduction.mp4`.
- Masquer noms, adresses e-mail, numéros, identifiants, jetons, données de compte et toute information personnelle.
- Ne jamais inclure de mots de passe, clés API, cookies ou données confidentielles.
- Noter dans le rapport l'environnement, la date et les étapes correspondant à la preuve.
- Respecter les conditions d'utilisation et les autorisations de test.

Aucune capture n'est ajoutée à ce stade : les preuves doivent provenir d'exécutions réelles et reproductibles.
